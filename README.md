# 矿安智盾 — 数字孪生主控舱

> 煤矿地下裂缝瓦斯监测与多机器人协同探测的数字孪生可视化平台

## 概述

矿安智盾是专为煤矿安全监测设计的数字孪生主控舱系统。通过三维可视化技术、实时传感器监测和AI辅助决策，实现对煤矿地下裂缝、瓦斯浓度等关键安全指标的实时掌控。

**核心功能**：
- 煤矿瓦斯裂缝监测
- 机器人集群管理
- AI 辅助决策

---

## 技术栈

| 层 | 技术 | 用途 |
|----|------|------|
| **前端** | React 18 + TypeScript + Vite | UI 框架与工程化 |
| **3D 渲染** | Three.js + React Three Fiber | 场景和相机管理 |
| **点云引擎** | Potree 1.8 | 十亿级点云 LOD 渲染 |
| **热力图** | Three.js 自定义 shader | 空间数据可视化 |
| **UI 组件** | Radix UI + Tailwind CSS | 无障碍组件与样式 |
| **状态管理** | Zustand | 全局状态 |
| **后端** | FastAPI (Python) | API 接口与数据处理 |
| **点云处理** | Open3D | 去噪/ICP/重建/RANSAC |
| **通信** | HTTP 轮询；WebSocket 预留 | 实时数据推送 |

## 系统视觉

### 主控舱界面

系统采用**深色工业设计风格**，充分利用屏幕空间展示复杂的地下空间数据：

- **中央 3D 场景** — Three.js 渲染的地下裂缝网络、岩体结构、机器人位置
- **Potree 点云渲染** — 十亿级点云的工业级八叉树 LOD 引擎，支持流畅缩放
- **瓦斯热力图** — 覆盖在 3D 场景之上的实时热力层，展示 CH₄/CO/H₂S 空间分布与异常区域
- **左侧监控面板** — 机器人集群列表、实时状态监测、告警信息、数据源切换
- **右侧分析面板** — 风险发现、目标识别、证据链追踪、AI 对话助手
- **下方工具栏** — 测量工具、标注工具、导出功能

### 监控与识别系统

#### 实时监控

- **多机器人实时追踪** — 地下机器人位置、速度、传感器数据同步显示
- **传感器数据流** — 甲烷/一氧化碳/硫化氢浓度实时采集与更新
- **告警机制** — 超限值自动触发红色警报，支持告警分级
- **集群状态看板** — 在线/离线/故障机器人数量统计、运行时间、电池状态

#### 目标识别

- **异常区域自动识别** — AI 算法识别瓦斯浓度异常点，标记为风险热点
- **裂缝结构识别** — 3D 点云中的裂缝走向、倾角、扩展趋势自动识别
- **塌方风险评估** — 结合岩体应力、声发射信号，识别塌方高风险区域
- **微震事件定位** — 多传感器数据融合，精确定位微地震事件位置与震级
- **关键特征标注** — 自动标注瓦斯泄漏点、结构薄弱区、设备异常位置

#### 数据可视化

| 监控指标 | 显示方式 | 交互方式 |
|---------|---------|---------|
| **瓦斯浓度** | 实时热力图，颜色等级表示浓度 | 鼠标悬停显示精确数值 |
| **机器人位置** | 3D 图标标记，支持追踪轨迹 | 点击查看单机详情面板 |
| **风险区域** | 红色/黄色/绿色分级标注 | 自动定位到异常点 |
| **告警信息** | 列表面板 + 实时通知 | 点击追踪事件来源 |
| **传感器数据** | 折线图趋势、分布直方图 | 时间范围筛选 |

### 交互特性

- **360° 自由旋转** — 鼠标拖拽控制相机视角
- **多层渲染** — 裂缝网络 + 岩体结构 + 点云 + 热力图 + 机器人标记分层显示
- **实时数据推送** — 机器人位置、传感器数据、告警信息实时更新
- **空间联动** — 点击点云/热力图异常点，自动弹出详情面板与证据链分析
- **暗黑模式** — 深色 UI 主题，适合长时间监控操作

## 应用场景

**煤矿地下裂缝监测**，重点监测指标：

- **甲烷浓度** (CH₄) — 爆炸危险预警
- **一氧化碳浓度** (CO) — 中毒风险监测
- **硫化氢浓度** (H₂S) — 毒气预警
- **微震事件** — 岩体结构稳定性
- **声发射事件** — 岩体应力释放

## 快速开始

### 前置要求

- Node.js 18+
- npm 或 yarn
- Python 3.8+ (可选)

### 前端启动
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
# 访问: http://localhost:5173
```
### 前端生产构建
```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览
```

### GitHub Pages 纯前端 Demo

项目默认使用 mock 数据，可作为不依赖 Python、FastAPI、Mine 推理服务和 WebSocket 的纯前端展示版运行。

1. 将仓库推送到 GitHub 的 `main` 分支。
2. 在仓库 `Settings > Pages > Build and deployment` 中选择 `GitHub Actions`。
3. 推送代码或在 `Actions > Deploy frontend demo to GitHub Pages` 中手动运行工作流。

工作流会执行 `npm ci` 和 `npm run build`，再将 `dist/` 发布到 Pages。真实后端模式需要另外部署服务，并通过 `VITE_API_MODE=live` 和 `VITE_API_BASE_URL` 配置连接地址。

### 后端启动（可选）
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
# API 文档: http://localhost:8000/docs
```
